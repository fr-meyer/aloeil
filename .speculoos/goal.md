# Aloeil goal

Deliver a trustworthy, accessible Android journal for manually recording and reviewing home eye-pressure readings.

The phone remains the authoritative working copy and must save while offline. History is separated by eye, repeated measurements remain individual facts, and optional backup cannot become a save gate.

Aloeil never diagnoses, scores risk, recommends treatment, defines clinical thresholds, scrapes unsupported device interfaces, or uses readings for advertising or model training. Repository work and automated tests use synthetic data only.
